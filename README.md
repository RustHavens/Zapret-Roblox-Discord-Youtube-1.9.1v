# Zapret-Roblox-Discord-Youtube-1.9.1v

Утилита для тестирования и обхода блокировок доступа к YouTube, Discord и Roblox, а также проверки стратегий сетевого соединения.

Основные функции и возможности:

Запуск тестов стратегий

Команда: service.bat -> Run Tests

Проверка сайтов из utils/targets.txt

Проверка DPI через DPI Checker

Обход ограничений Discord и Roblox

Изменён обход UDP для Discord во всех стратегиях (commit 2d8f7c0)

Новые стратегии ALT11, SIMPLE FAKE ALT2 на основе TLS Макса (commit 59f26cc)

Переделана стратегия ALT3 (commit 95a23d6)

Изменён фулинг в FAKE TLS AUTO ALT и SIMPLE FAKE ALT (commit e88c07d)

Дамп TLS ClientHello с Макса (commit #6645)

Управление обновлениями и настройками

Возможность отключить автоматическую проверку обновлений

Создана папка utils с файлами:

GameFilter — флаг для игр

targets.txt — список сайтов для проверки утилитой

Диагностика и поддержка сети

Обновлён список подсетей (commit #7136)

Добавлены проверки системного PATH и разархивации (commit 528b707 и 651342d)

Обновлён ipset-exclude.txt для исключения IP (commit #6419)

Исправлено уведомление о безопасности Windows (commit #7184)

Улучшен вывод "Check Status" в service.bat (commit #6488)

Вывод VPN-сервисов в диагностике (commit #6135)

Особые примечания и рекомендации

При бесконечном подключении к RTC Discord (или проблемах с демонстрацией экрана) рекомендуется удалить строку:

--dpi-desync-fake-discord="%BIN%quic_initial_www_google_com.bin" --dpi-desync-fake-stun="%BIN%quic_initial_www_google_com.bin"


Проблемы с голосовыми каналами Discord (Финляндия) с 23 декабря могут потребовать смены региона канала (например, на Rotterdam).
